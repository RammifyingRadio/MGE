# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately to the repository owner rather than opening a public issue. Include the affected path or component, a concise description, reproduction steps, and any relevant impact assessment.

Do not include passwords, access tokens, private keys, or other live credentials in reports or commits.

## Repository hygiene

- Keep credentials and machine-local secrets out of version control.
- Prefer short-lived, least-privilege tokens.
- Review changes before pushing configuration backups.
- Revoke and rotate any credential that may have been exposed.

This repository may contain private configuration or archival material; access should be limited to intended collaborators.
